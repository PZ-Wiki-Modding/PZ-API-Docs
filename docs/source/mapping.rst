Mapping
=======

Various documentations used for `mapping <https://pzwiki.net/wiki/Mapping>`_. You will find documentations of tile properties, room names and the procedural distributions.

Procedural distributions is the system used to manage the loot of the game. Different rooms will contain different distributions, which are lists of items that can be found in that room and different properties of those found items.

.. note::
   For more information, see the wiki page about `Procedural distributions <https://pzwiki.net/wiki/Procedural_distributions>`_.
